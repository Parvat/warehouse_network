# Hero image

Drop a file here named `hero-warehouse.jpg`. Until you do, the page shows a
labelled placeholder — nothing breaks.

## What works

- **Landscape**, 2000 x 1400 or larger
- **Loaded pallet racking receding down an aisle** — perspective, not a flat elevation
- **Bright and low contrast on the left third**, because the headline fades over it
- Warm neutral tones suit the palette; heavy blue or cool grey will fight the pine green

## Sourcing

Your own site photos are best — copyright-clean, and they show your actual market.
A wide shot down a finished aisle from an install you have done is ideal, and doubles
as proof the racking is real work rather than stock imagery.

If you buy stock, search "warehouse pallet racking aisle" and prefer shots without
visible branding, people's faces, or licence plates.

## Swapping it out

No code change needed — just drop the file in.
